## Authentication

Most API endpoints require authentication. Three methods are supported:

| Header | Description |
|--------|-------------|
| `x-sync-password` | Your sync password for Cloud Sync endpoints |
| `x-autopilot-token` | Per-account token for Autopilot endpoints |
| `x-sync-user` + `x-sync-password` | Provider endpoints use both user ID and derived password |

## Quick Example

```bash
curl -X GET "https://your-server.com/api/health" \
  -H "Content-Type: application/json"
```

**Response:**
```json
{
  "status": "ok",
  "version": "2.0.0 (Build 2)",
  "mode": "multi-tenant",
  "optimized": true,
  "database": { "type": "sqlite", "healthy": true },
  "autopilot": { "lastRun": 1700000000000, "running": false }
}
```
