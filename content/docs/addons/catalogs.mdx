---
title: Catalog Editor
description: Reorder or hide catalogs within an addon.
---

The Catalog Editor lets you control which catalogs an addon exposes in Stremio and in what order they appear. Access it via the **Catalogs** button in the 2×2 action grid on any addon card. The button is disabled for addons that have no catalogs.

## Reorder & Remove

**Reorder:** Drag and drop catalog rows to change the order they appear in Stremio's home screen. The top catalog becomes the first one visible.

**Remove a catalog:** Toggle off any catalog you don't want to see. Removed catalogs are stored in an override list; the addon manifest itself is untouched, so you can restore them at any time.

**Reset:** Click Reset to restore the addon's default catalog list and order.

<Tip>Changes are pushed to Stremio immediately. The next time you open the Stremio app, the updated catalog order and visibility will be reflected.</Tip>
