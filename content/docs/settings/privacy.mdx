## See the result before sharing

Open **Settings > General > Privacy Mode**. Turn it on to reveal the controls and a live sample account card. The card uses fictional data, so you can explore the masking levels without exposing an account.

Choose a level for **Account Names**, **Addon URLs**, **Profile Names**, and **Email**. Each control updates the sample in place and applies the same masking functions used throughout the app. Use **Show original sample** to compare the fictional details with their masked appearance.

## Choose how much to show

| Level | What to expect |
| --- | --- |
| Off | The selected kind of data stays visible, even while Privacy Mode is on. |
| Light | Keeps enough context to recognize the item. For example, an addon URL keeps its hostname and hides its path. |
| Strict | Shows less identifying detail. Profile names become a profile count where the view provides one, or a masked placeholder. |
| Hidden | Replaces the value with a masked placeholder. |

The exact result depends on the kind of data. Use the preview to inspect each one instead of assuming that the same level produces the same pattern everywhere.

## What Privacy Mode changes

Privacy Mode changes how supported fields appear in the interface. It does not edit the underlying account information, remove addon configuration, or revoke credentials. An unmasked value may still be needed for an export or an action that copies the original data.

Before sharing a screenshot, check the page you intend to share. The sample explains the controls; it is not a scan of that page for sensitive information.

Turning Privacy Mode off restores the usual display. Your selected masking levels are kept for the next time you enable it.
