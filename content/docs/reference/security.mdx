## Local Encryption

All AuthKeys and passwords are encrypted using **AES-256-GCM** directly in your browser before being stored in IndexedDB. The encryption key is derived from your Master Password using PBKDF2. AIOManager's servers never receive your credentials or addon configurations in plaintext, only ciphertext.

<Warning>If you forget your Master Password, your encrypted data cannot be recovered. There is no password reset, as the server never sees your key.</Warning>

## Server-Side Protection

**Autopilot Rule Encryption:** Autopilot rules stored on the server, including embedded Stremio auth keys, are encrypted at rest using AES-256-GCM with the server's `ENCRYPTION_KEY`.

**SSRF Protection:** All proxy and manifest fetch requests are validated before execution. Localhost, private IP ranges (10.x, 172.16-31.x, 192.168.x), and link-local addresses are blocked.

**Rate Limiting:** API endpoints are individually rate-limited. The sync endpoint allows 60 requests/minute, proxy endpoints 30/minute, health checks 30/minute.

**Password Verification:** Sync passwords are verified using timing-safe comparison to prevent timing-based enumeration attacks.

**Input Validation:** All addon URLs and webhook URLs are validated against allowlists before processing. SQL queries use parameterized statements throughout.

## Encryption Key Management

If `ENCRYPTION_KEY` is not set in your `.env`, the server auto-generates a secure 32-byte key on first boot and saves it to `DATA_DIR/server_secret.key`. Back this file up; losing it means existing encrypted Autopilot data cannot be decrypted.

If you later set a manual `ENCRYPTION_KEY`, the server uses the new key for new data and automatically falls back to the old `server_secret.key` for existing data. No one is locked out.

<Note>AIOManager must be served over HTTPS or localhost. Plain HTTP connections block the browser's Web Crypto APIs required for the Key Vault and Cloud Sync.</Note>

## Remembered Devices

**Remember this device** is an opt-in saved sign-in that skips the UUID and password on return visits. It is built so a saved device never becomes a copy of your password:

- The server stores only a **scrypt hash** of a random per-device token. It can verify the token, never read it, and can revoke it independently of your password.
- Your vault and sync keys are stored in the browser **wrapped** (AES-256-GCM under an HKDF-derived key) together with that token. Without the device secret they are unreadable.
- On capable devices the device secret is derived from a **passkey held in your device's secure hardware** (TPM / Secure Enclave) and never touches browser storage at all.
- Your password is not stored anywhere by this feature, and revoking a device does not require changing it.

A device token expires after 180 days without use and dies immediately if your password changes or you revoke it from Settings. Full walkthrough: [Remember This Device](/kronorium/getting-started/remember-this-device).

## Privacy

AIOManager does not collect telemetry or tracking data. All your data stays on your own infrastructure. The only external connections made are to the Stremio API (for account syncing) and the addon URLs you install.

**Privacy Mode** in Settings masks account emails and sensitive data across the UI, which is useful for screenshots or screen sharing. It persists across reloads via localStorage.
