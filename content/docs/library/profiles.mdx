## Profiles

Profiles are named groups you create in the Library sidebar. Assign saved addons to a profile to keep them organised, for example a "Debrid" profile with your AIOStreams configs or a "Family" profile with kid-friendly addons.

You can deploy an entire profile to an account in one click using **Install from Library** in Batch Operations or the account card menu. Drag the grip handle in the sidebar to reorder profiles.

<Tip>Profiles are separate from the account sidebar profiles. Library profiles are for organising saved addons, not for labelling accounts.</Tip>

## Tags

Tags are free-form labels applied to individual saved addons. An addon can have multiple tags.

**Filtering:** Filter the Library view by tag to quickly find the addons you want.

**Bulk install:** Install all addons with a specific tag to an account via Batch Operations > Install from Library.

**Bulk remove:** Remove all addons with a specific tag from selected accounts via Batch Operations > Remove by Tags.

Tags are case-insensitive; "Action" and "action" are the same tag.
