---
title: Bulk URL Replace
description: Quickly migrate dozens of addons to a new domain or configuration.
---

The Bulk URL Replace tool is designed for situations where an addon provider changes their domain, or you want to update a configuration string (like a debrid API key) across many addons at once. Instead of editing each addon one by one, you can perform a find-and-replace across your entire saved library.

## Using the Tool

<Steps>
  <Step>**Access the Tool:** Go to the Library tab and click the 🔄 Bulk Replace button in the toolbar.</Step>
  <Step>**Enter Search String:** Type the part of the URL you want to change (e.g., the old domain name).</Step>
  <Step>**Enter Replacement String:** Type the new value you want to replace it with.</Step>
  <Step>**Review Changes:** AIOManager will show you a list of all addons that will be affected. Uncheck any you want to skip.</Step>
  <Step>**Apply:** Confirm the changes. All affected addon URLs are updated in your Library. Use Reinstall or Refresh Addons on your accounts to push the updated URLs to Stremio.</Step>
</Steps>

<Note>Bulk Replace only affects the install URL. It does not touch your custom names, logos, or descriptions.</Note>

## Scope: Library vs. a single account

There are three places to run a find-and-replace:

- **Library tab (this tool):** matches your saved addons and propagates each URL change everywhere it is used. This is the right choice for a domain migration that should apply across every account.
- **A single account (Bulk Actions menu):** open an account, then use **Bulk Actions → Find & Replace URL**. This matches the addons installed on that one account, including any that were never saved to your Library, and changes only that account. Your Library is left untouched, so a replaced addon may show as no longer saved.
- **Several accounts at once (Accounts tab):** select the accounts, open Batch Operations, and choose **Find & Replace URL** under Manage. This rewrites matching addon URLs across just the selected accounts, again including addons that were never saved to your Library. Use this when a domain change should apply to some accounts but you do not want to touch your Library or every account.

<Note>The single-account and multi-account tools re-fetch each addon at its new URL before applying the change. If a new URL is unreachable, that addon is skipped and reported, so the new domain should be live before you run them.</Note>
