---
title: Connections
description: Mirror addon configurations to external platforms and keep them in sync.
---

Connections let you mirror your AIOManager addon configuration to external platforms. When you add, remove, or reorder addons on any connected platform, the reconciler propagates those changes to all others.

## Supported Platforms

| Platform | Auth | Notes |
|----------|------|-------|
| Stremio | Stremio login | Direct Stremio API integration. Your primary account is the source of truth. |
| Nuvio | Email/Password | Connect through Supabase. Supports multiple profiles per connection. Server-side token custody with automatic refresh. |
| RealStream | Email/Password | Native integration with server-side token custody. |

## Setup

### Connecting a Platform

1. Open an account and navigate to the **Connections** tab.
2. Click **Add Connection** and choose the platform.
3. Enter the required credentials (email/password, Stremio login, etc.).
4. Click **Test** to verify connectivity before saving.

Each account can have multiple connections to different platforms.

### Connection Credentials

Credentials are encrypted at rest on the server using AES-256-GCM. After initial setup, credentials are never exposed to the client. The server handles token refresh and session management automatically.

<Warning>Connection credentials are per-account. Sharing credentials between accounts is not supported.</Warning>

## Connecting other apps (Hydra)

Some apps don't run their own backend. AIOManager exposes the **Hydra** protocol so they can use your managed addon collection instead of reinventing addon management. There is nothing to add for this; it works through your account **API key** (found on the **API Key** tab of the account).

### Apps that pull from you

This is the common case. A backendless app, for example Fusion (which syncs across your devices over iCloud), **pulls** your addon list directly from AIOManager. You do not add a connection in AIOManager for it:

1. In the app, enter your **AIOManager instance URL** and your **account API key**.
2. Once the app syncs, it appears in your **Connections** list as a card alongside your other platforms, marked **Pull**, with a Synced/Stale indicator and its last-sync time.

<Callout type="info">
  No apps currently support this integration yet. Fusion is used here as an example of the type of app Hydra is designed for, but it does not yet have AIOManager support.
</Callout>

The app reads, and if it supports it updates, your addons through the [Hydra API](/kronorium/api/hydra). Your key stays in the app; AIOManager never holds the app's credentials. A pull app can't be toggled or pushed to from AIOManager (there's no server to reach); to stop one, remove its card from **Connections** or rotate your API key.

### Pushing to another server (advanced)

If you run a Hydra-compatible server, you can **push** your collection to it. This lives behind **Add Connection → Advanced → push to another server**, where you enter the destination URL and its auth. It then mirrors and runs Autopilot like any other connection.

## Reconciler

The bidirectional reconciler is the sync engine that keeps all connected platforms in agreement.

### How It Works

1. **Hub-First**: Your AIOManager account's addon list is the canonical truth. Connections are mirrors.
2. **On Sync**: When a sync runs, the reconciler reads the addon list from each connected platform and compares it against the canonical list.
3. **Change Detection**: Additions and removals detected on any platform are propagated to all others.
4. **Conflict Resolution**: If an addon exists on a connected platform but not in the canonical list, it is added. If it was removed from the canonical list, it is removed from the connection.

### Sync Triggers

- Manual sync from the Connections panel
- After addon install/remove operations
- After profile switches

### Connection States

| State | Description |
|-------|-------------|
| `active` | Connection is healthy and syncing normally. |
| `degraded` | Connection has intermittent failures but is still operational. |
| `expired` | Authentication token has expired. Re-authenticate to resume syncing. |
| `error` | Connection has persistent failures. Check credentials and platform availability. |

## Troubleshooting

**Connection shows `expired`**: The stored authentication token has expired. Click the connection card and re-authenticate with your credentials.

**Sync not detecting changes on a platform**: The reconciler runs against the canonical addon list. If external changes were made outside AIOManager, trigger a manual sync to pull them in.

**Nuvio profile not syncing**: Verify the correct profile is selected in the connection settings. Nuvio supports multiple profiles per account, and each connection targets a specific profile.

**An app that should pull isn't showing in Connections**: It only appears after its first successful sync. Confirm the app has your correct AIOManager URL and account API key. If you rotated the key, update it in the app.

**Outbound (push) connection fails with `Provider unreachable`**: Check that the destination server is running and reachable from your AIOManager instance. Verify the base URL and auth are correct.
